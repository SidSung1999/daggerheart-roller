# Google 試算表「匯出頁」格式

網頁的「Google 匯入」按鈕會讀你的試算表裡一個叫 **匯出頁** 的分頁，匯入成一個**新角色**（不會覆蓋現有角色）。
你只要在這個分頁用公式把角色卡上的資料整理成下面的格式，之後角色卡版面怎麼改，都只需要調整這個分頁。

可以先用 `docs/匯出頁範本.csv`（Google 試算表：檔案 → 匯入 → 上傳 → 插入新工作表）建一個範本，再把範例值換成指向角色卡的公式。

## 基本規則

- A 欄是**欄位名稱**，B 欄以後是**值**。第一列的標題（欄位、值…）會被忽略。
- 不認得的欄位、空白列會略過；匯入完成後會列出不認得的欄位名稱，方便你抓打錯字。
- 欄位名稱的空白與大小寫不拘（`HP 上限` 和 `HP上限` 一樣）。
- **數值填角色卡上印出來的合計**。程式會自己扣掉種族加成、護甲、等級、力量，還原成內部的基礎值，不會重複計算。
- 打勾用 Google 試算表的勾選框（TRUE / FALSE），或寫「是」「否」。
- 清單類欄位**每筆一列**，A 欄重複寫同一個欄位名稱。
- 名稱要和資料庫一致，但只比對第一個詞，所以寫「盜賊」或「盜賊 Rogue」都可以。
  適用：種族、背景、轉變、職業、子職、武器、護甲、領域卡。找不到時會當成自訂名稱，並在匯入結果提醒你。

## 單一值（只用 B 欄）

| 欄位 | 說明 |
|---|---|
| 角色名、玩家 | |
| 等級 | 1 到 10 |
| 熟練值 | |
| 種族、背景、轉變 | 轉變可留空 |
| 職業、子職 | 選了會自動帶入領域、職業特性、子職基礎特性 |
| 職業2、子職2 | 兼職才填。會帶入兼職領域與職業 2 的職業特性 |
| 金幣、角色設定、個人資源 | 文字 |
| 閃避、HP上限、壓力上限 | 角色卡上印的合計（含種族加成） |
| 護甲值 | 護甲槽數的合計 |
| 中度傷害閾值、重度傷害閾值 | 角色卡上印的合計（護甲基礎值 + 等級 + 其他） |
| HP已標記、壓力已標記、護甲已標記 | 已經勾掉幾格 |
| 希望 | 目前有幾點希望 |
| 領域 | 選填，B、C 欄各填一個領域。通常不用填，選了職業就會自動帶入 |

## 清單（每筆一列）

| 欄位 | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| 屬性 | 名稱（敏捷／力量／技巧／直覺／風采／知識） | 數值 | 已升級（勾選） | | | |
| 經歷 | 名稱 | 加值 | | | | |
| 主手武器 | 名稱 | 屬性* | 特徵* | 射程* | 傷害* | 類型* |
| 副手武器 | 名稱 | 屬性* | 特徵* | 射程* | 傷害* | 類型* |
| 庫存武器 | 名稱 | 屬性* | 特徵* | 射程* | 傷害* | 類型* |
| 護甲 | 名稱 | 基礎傷害閾值*（例：5 / 11） | 特徵* | 基礎護甲值*（例：3 或 3 + 力） | | |
| 領域卡 | 名稱 | 領域* | 已準備（勾選） | | | |
| 物品 | 名稱 | 數量 | 描述 | | | |
| 特性 | 來源 | 名稱 | 描述 | | | |
| 升級紀錄 | 階級（2／3／4） | 選項 | 次數 | | | |
| 混合血統 | 種族 A | 種族 B | 混合種族名稱 | | | |

**欄位順序有彈性**：屬性列的「數值」「已升級」、領域卡的「領域」「已準備」，不管排在哪一欄都讀得到（程式會判斷哪格是數字、哪格是勾選值、哪格是領域名稱）。其他寫法也接受：A 欄留白的列沿用上一列的欄位名稱；屬性可以直接用屬性名稱當欄位名稱（`敏捷 | 2 | TRUE`）。數值可以寫 `+2`、`-1`，全形數字也可以。

匯入完成的視窗會列出「讀到的內容」（屬性、經歷、領域卡、武器…）讓你核對，讀不到或看不懂的地方會列在下方提醒。

標 `*` 的欄位可以留空：武器、護甲、領域卡的名稱在資料庫裡找得到時，其他欄位會自動帶入；只有自製的才需要填。有填的欄位優先。

- **特性**：只放程式不會自動帶入的自訂特性。種族、背景、轉變、職業、子職的特性會依名稱自動帶入，不用再填。
- **混合血統**：種族填「混合血統」時才用。特性 1 取自種族 A、特性 2 取自種族 B（兩者必須不同）。
- **領域卡**：已準備的最多 5 張，超過的會改成未準備。
- **主手是雙手武器時**，如果也填了副手，副手會自動移到庫存。

### 升級紀錄的選項名稱

階級 2、3、4 各列出「選過幾次哪些選項」，用來判斷之後升級還能選什麼，也決定要不要帶入專精、大師特性。

| 選項 | 每個階級最多 | 備註 |
|---|---|---|
| 屬性 | 3 | |
| HP上限 | 2 | |
| 壓力上限 | 2 | |
| 經歷 | 1 | |
| 領域卡 | 1 | |
| 閃避 | 1 | |
| 升級子職業 | 1 | 只有階級 3、4。階級 3 會帶入專精特性、階級 4 帶入大師特性 |
| 熟練值 | 1 | 只有階級 3、4。算 2 個名額 |
| 兼職 | 1 | 只有階級 3、4。算 2 個名額 |

例：`升級紀錄 | 2 | 屬性 | 2` 表示階級 2 選了兩次「屬性」。

下列簡寫也看得懂：`領域`＝領域卡、`升級子職`／`子職升級`＝升級子職業、`熟練`＝熟練值、`生命`＝HP上限、`壓力`＝壓力上限、`閃避值`＝閃避。階級只能填 2、3、4。看不懂的列會略過，並在匯入結果提醒。

沒有填升級紀錄也能匯入，只是之後升級時，網頁不知道哪些選項已經用過，會提醒你補登。

## 設定 Google 端（一次就好）

> API Key 的完整步驟（含出錯排除）見 `Google-API-Key設定.md`，下面是簡版。

1. **共用**：試算表右上角「共用」→ 一般存取權 →「知道連結的任何人」→ 角色「檢視者」。
2. **建立 API Key**（只需要建一次，所有人共用同一個）：
   1. 開 <https://console.cloud.google.com/>，建立專案。
   2. 「API 和服務」→「程式庫」→ 搜尋並啟用 **Google Sheets API**。
   3. 「API 和服務」→「憑證」→「建立憑證」→「API 金鑰」。
   4. 編輯這把金鑰做限制：
      - 應用程式限制：**HTTP 參照網址**，加入 `https://你的帳號.github.io/*`，本機測試再加 `http://localhost:8080/*`。
      - API 限制：只勾 **Google Sheets API**。
3. 把金鑰填進 `js/config.js` 的 `GOOGLE_API_KEY`（朋友就不用各自貼），或在匯入視窗貼上（只存在那台瀏覽器）。

金鑰會公開在網頁程式碼裡，所以第 4 步的限制一定要做。
