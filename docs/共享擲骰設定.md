# 共享擲骰：設定 Firebase（做一次就好）

加入同一個房間代碼的人，會即時看到彼此的擲骰結果。連線用 Firebase Realtime Database，
免費方案（Spark）夠一個跑團使用：同時連線上限 100、儲存 1 GB、每月下載 10 GB
（[官方說明](https://firebase.google.com/docs/database/usage/billing)、[上限](https://firebase.google.com/docs/database/usage/limits)）。
一筆擲骰紀錄大約幾百位元組，用量遠遠不到上限。

> 介面文字依帳號語言顯示，下面用英文名稱，位置可能因 Google 改版略有不同。
> 請用**個人 Google 帳號**，不要用公司帳號。

## 步驟 1：建立 Firebase 專案

1. 開 <https://console.firebase.google.com/>，**Create a project**（建立專案）。
2. 名稱例如 `daggerheart-roller`。
3. Google Analytics 可以關掉（用不到）。建好後按 Continue。

## 步驟 2：建立 Realtime Database

1. 左側選單 **Build** → **Realtime Database** → **Create Database**。
2. 位置（Location）選離你們近的；清單裡有新加坡（`asia-southeast1`）的話選它。位置建立後不能改。
3. 安全規則選 **Start in locked mode**（鎖定模式），按 Enable。
4. 建好後，資料頁最上方會有一串網址，像 `https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app`，這就是 `databaseURL`。

## 步驟 3：啟用匿名登入

匿名登入讓每個瀏覽器自動拿到一個身分代碼（uid），玩家**不需要**註冊或輸入帳密，畫面操作不變。
資料庫規則用這個 uid 限制「每個人只能寫自己的資料」，別人無法冒用你的名義送擲骰，也無法刪掉你的在線狀態。

1. 左側選單 **Build** → **Authentication** → **Get started**（第一次使用才會出現）。
2. **Sign-in method**（登入方式）分頁 → **Add new provider** → 選 **Anonymous**（匿名）→ 開啟 **Enable** → **Save**。

身分記在瀏覽器裡：同一個瀏覽器重開網頁還是同一個身分；換電腦、用無痕視窗或清除網站資料會變成新的身分（不影響使用）。

## 步驟 4：貼上資料庫規則（重要）

進 Realtime Database → **Rules** 分頁，整段換成下面的內容，按 **Publish**：

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        "rolls": {
          "$id": {
            ".write": "auth != null && !data.exists() && newData.child('uid').val() === auth.uid",
            ".validate": "newData.hasChildren(['uid','t','by','title','text','total']) && newData.child('t').isNumber() && newData.child('by').isString() && newData.child('by').val().length <= 40 && newData.child('title').isString() && newData.child('title').val().length <= 200 && newData.child('text').isString() && newData.child('text').val().length <= 3000 && newData.child('total').isNumber()"
          }
        },
        "presence": {
          "$cid": {
            ".write": "auth != null && (data.exists() ? data.child('uid').val() === auth.uid : newData.child('uid').val() === auth.uid)",
            ".validate": "newData.hasChildren(['uid','name']) && newData.child('name').isString() && newData.child('name').val().length <= 40"
          }
        }
      }
    }
  }
}
```

這份規則的意思：
- 只開放 `rooms/房間代碼` 底下的資料，其他路徑完全不能讀寫；沒有登入（沒有 uid）的請求一律拒絕。
- 擲骰紀錄只能「新增」，不能修改或刪除，而且紀錄裡的 uid 必須是送出者自己的（不能冒用別人）；欄位格式與長度有限制。
- 在線名單：每一筆只有建立它的人能修改或刪除（斷線時程式會自動移除）。

**仍然要注意**：任何人打開網頁都能拿到匿名身分，所以**知道房間代碼的人還是能加入、看到內容、送出擲骰**，
顯示名稱也可以自己取。規則保護的是「不能改或冒用別人的資料」。房間代碼請取長一點、別人猜不到的。
紀錄裡只有擲骰結果與你填的顯示名稱。要清掉舊紀錄，到 Firebase 主控台的資料頁手動刪除那個房間即可。

### 從舊版規則升級（已經在用共享房間的人）

順序很重要，照這個順序就不會有人斷線：
1. 先做步驟 3（啟用匿名登入）。
2. 把新版網頁 commit、push 上 GitHub Pages，請同桌的人重新整理（Ctrl+Shift+R）。新版網頁在舊規則下也能正常使用。
3. 最後才貼上上面的新規則。還在用舊網頁（沒重新整理）的人，這時會看到「沒有權限」，重新整理即可。

## 步驟 5：取得 firebaseConfig

1. 左上角齒輪 → **Project settings**（專案設定）。
2. 「Your apps」區塊按 **`</>`**（Web）新增一個網頁應用程式，名稱隨意，**不用**勾 Firebase Hosting。
3. 註冊後會顯示一段 `const firebaseConfig = { ... }`，把裡面的值複製起來。
   如果裡面沒有 `databaseURL`，補上步驟 2 看到的那串網址。

## 步驟 6：填進網頁

打開 `js/config.js`，把值填進 `FIREBASE_CONFIG`：

```js
const FIREBASE_CONFIG = {
  apiKey: '...',
  authDomain: '...',
  databaseURL: 'https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app',
  projectId: '...',
  appId: '...',
};
```

存檔、commit、push。這些值本來就會出現在網頁裡，不是祕密，安全靠步驟 3、4 的匿名登入與規則。

## 步驟 7：使用

1. 每個人開網頁，按上方「🌐 房間」，輸入同一個**房間代碼**和自己的**顯示名稱**，按加入。
2. 加入後右下角會出現「擲骰紀錄」，列出房間裡所有人的結果。點每一筆可以展開細節（每顆骰子、希望／恐懼骰、判定）。
3. 擲骰器（動作檢定、反應檢定、傷害、法術）和「自由擲骰」擲出的結果，都會自動送到房間。
4. 想私下擲骰（例如 GM 暗骰）：把紀錄面板裡的「分享我的擲骰」取消勾選。你仍然看得到別人的。
5. 重新整理頁面後，會自動回到上次的房間。

## 出錯時

| 看到的訊息 | 可能原因 |
|---|---|
| 尚未設定 Firebase | `js/config.js` 的 `databaseURL` 還是空的 |
| 沒有權限讀寫這個房間 | 步驟 4 的規則沒貼好或沒按 Publish；或用的是舊版網頁（請重新整理） |
| Firebase 還沒有啟用匿名登入 | 步驟 3 沒做，或 Anonymous 沒按 Save |
| 匿名登入失敗 | `apiKey` 填錯；或在 Google Cloud 對這把金鑰設了「API 限制」，要把 **Identity Toolkit API** 加進允許清單 |
| 載入 Firebase 失敗 | 網路連不到 `gstatic.com`，或被公司網路擋住 |
| 匿名登入失敗（unauthorized-domain） | Authentication → Settings → Authorized domains 加上網站網域（例如 `g23598750.github.io`）；`localhost` 預設已在清單 |
| 看得到別人，別人看不到我 | 檢查「分享我的擲骰」有沒有勾選 |
